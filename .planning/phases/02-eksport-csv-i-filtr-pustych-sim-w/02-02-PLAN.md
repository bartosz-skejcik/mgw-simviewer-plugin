<objective>
Dodaj natywny eksport CSV (EXP-01) sterowany serwerowo opcją enable_export (EXP-02). The plugin's templates/list.html.twig already does `{% include 'components/datatable.html.twig' with datatable %}`, so adding a `csv_url` key to the `datatable` array in show() is sufficient — NO twig change needed, and the native-button contract is confirmed (no fallback required).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> front/export.php | Untrusted GET (filter param, possibly forged/direct URL) crosses into the CSV endpoint |
| front/export.php -> getRows() -> DB | Export must reuse the single scoped data path, never its own query |
| CSV file -> spreadsheet app | Exported cell values opened in Excel/Calc — formula-injection surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Information disclosure | front/export.php sensitive fields | high | mitigate | Export reads only Simcard::getRows() output (User/phone/serial/status); getRows never selects PIN/PUK/PIN2/PUK2/MSIN; export adds no SQL/SELECT of its own |
| T-02-06 | Elevation of privilege | front/export.php access control | high | mitigate | Session::checkRight(plugin_simviewer, READ) first; then enable_export gate -> Html::displayRightError (403) when disabled; direct-URL access blocked when export off (SC2) |
| T-02-07 | Information disclosure | entity scoping / show_unassigned bypass | high | mitigate | Filter/entity scoping enforced in getRows() SQL; export shares that path — cannot bypass by hitting the endpoint directly |
| T-02-08 | Tampering | CSV formula injection | medium | mitigate | Cells starting with =,+,-,@,tab,CR prefixed with apostrophe before write (escape decision documented) |
| T-02-09 | Tampering | HTTP method / state mutation | medium | mitigate | GET-only, read-only; no POST handling, no write calls — endpoint mirrors front/simcard.php contract |
| T-02-SC | Tampering | dependency installs | low | accept | Phase adds NO third-party packages (npm/pip/cargo); no package legitimacy gate applicable |
